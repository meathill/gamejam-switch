## 序章

【场景切入】

【旁白】

浑浊的洪水淹过街道，路灯在水面上摇晃。汽车、木箱和广告牌被水流推着撞向居民楼。远处的高架桥已经断裂，楼房之间只剩下一片看不到尽头的黑水。雨还在一直下，没有要停的意思。

一只湿透的狸花猫站在居民楼屋顶。

屋顶对面楼房的楼层有一晃而过的人影，手电筒的光透过窗户一闪一闪。

白光闪过，雨幕中浮现一道残缺的圆环，光芒时明时暗。

【切UI界面】对话

- 【伊尔妲】你还要留在这里？
- 【伊尔妲】水马上就会淹过屋顶。
- 【小猫】我知道。
- 【伊尔妲】那你为什么不走？
- 【小猫】她给过我吃的。
- 【伊尔妲】只是因为几顿食物？
- 【小猫】不止。
- 【伊尔妲】......
- 【伊尔妲】人类把河封进地下，在它身上盖满了楼房和马路。他们填平湿地，砍光林，以为水会永远听话。但是河回来了，它会带走这里的一切。
- 【伊尔妲】这是他们自己选择的。
- 【小猫】......没有别的办法吗？
- 【伊尔妲】我的身体被破坏，神力被污染，我救不了她们
- 【伊尔妲】但我可以把一点力量分给你。用它做什么，由你决定。
- 【小猫】什么样的力量？
- 【伊尔妲】让天气听话的力量。
- 【伊尔妲】雨会让水涨起来。
- 【伊尔妲】风会推着东西走。
- 【伊尔妲】雪会让水结冰。。
- 【伊尔妲】日照会融化冰，也会让水退去。
- 【小猫】好。
- 【系统提示】是否接受伊尔妲的力量？[接受/拒绝]

猫的额头浮现出金色的嫩芽印记。身后那道残缺的圆环中，有一段亮了起来。

- 【系统提示】获得能力：雨/风/雪/日照
- 【伊尔妲】这是我仅剩的力量了。

残缺的圆环中，一颗发着微光的种子缓缓落下，停在猫的脚边。

- 【伊尔妲】如果你在路上看见还能活下去的土地，替我种下一颗种子。
