## 二、第一关

### 核心玩法与规则

#### 1 玩家循环

观察当前天气与水位 → 切换天气 → 观察环境状态变化 → 选择步行或浮箱路线 → 移动小猫咪 → 救援居民 → 前往高地

#### 2 第一关天气切换

| 天气 | 环境效果                                        | 第一关用途                                              | 限制与反馈                                             |
| ---- | ----------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| 雨天 | 当前选中的液态水区域水位上涨1级，最高为2。      | 填满排水槽和浮箱水道，开启浮箱路线；也可能淹没低地。    | 不能超过水位2；雨幕、雨声和水位动画必须同时反馈。      |
| 雪天 | 当前液态水区域结冰，保留原水位。                | 把深水面变成可行走的冰面，打开居民楼或广场的步行路线。  | 结冰后浮箱不能移动；冰面需要明显的蓝白视觉和滑行反馈。 |
| 风天 | 液态水中的浮箱沿预设停靠点移动一格。            | 在F浮箱转运区调整浮箱路线，把居民送到正确的高地停靠点。 | 只对液态水中的浮箱有效；冰面上的浮箱不移动。           |
| 日照 | 冰面可以融化为同水位的液态水；液态水可下降1级。 | 解除结冰状态，或者降低水位露出低地道路。                | 对污染水不直接完成净化；无效时显示原因，不改变状态。   |

天气切换是第一关的核心操作：玩家先选择雨、雪、风或日照，再对当前选中的环境区域执行一次天气变化。天气不会全屏同时改变环境，避免玩家无法判断因果关系。每次变化都必须同时更新水位、地形表现、浮箱状态和可通行路线。

#### 3 水位状态

| 水位   | 表现                     | 小猫咪行为                     | 浮箱行为                   |
| ------ | ------------------------ | ------------------------------ | -------------------------- |
| 0 干燥 | 地面、裂缝和垃圾清晰可见 | 可以正常行走；部分低洼路可通过 | 浮箱无法移动               |
| 1 浅水 | 水面覆盖脚踝或道路低处   | 可以通过但移动略慢             | 浮箱停靠，不进入远距离移动 |
| 2 深水 | 水面覆盖道路，出现漂浮物 | 不能直接通过，需要浮箱或高地   | 可以使用风移动一格         |

#### 4 救援规则

第一关设置两名居民。居民不进行自由移动，只在指定地点等待救援。玩家需要把浮箱移动到居民所在的停靠点，或者先降低水位打开步行路线。到达居民附近后按E触发救援，居民会沿预设动画或传送路线前往安全点。

- 居民1：居民楼二层窗口，需要浮箱到达E区域后救援。
- 居民2：被困在被淹广场的公交站，需要先启动排水站，再通过浅水区抵达。
- 可选目标：城市绿化修复点，不影响主线通关，但用于表现自然恢复。

### 地图结构与灰盒规格

#### 1 总体地图

```text
A 起点城市低地 → B 积水街道 → C 废弃排水站 → D 被淹广场 → E 居民楼 → F 浮箱转运区 → G 高地避难所 → H 城市边缘
                                                                                      ↘ 支路：城市绿化修复点
```

地图采用主路线加一条短支路结构。主路线必须始终可读，支路只承担额外修复和剧情反馈，不允许支路成为通关必经的复杂迷宫。

#### 2 区域节点设计

| 节点            | 区域功能       | 玩家任务                         | 关键资源                 | 规格              |
| --------------- | -------------- | -------------------------------- | ------------------------ | ----------------- |
| A 城市低地      | 出生与教学     | 学习移动、观察水位、看到洪水背景 | 小猫咪、城市低地、暴雨   | 0.3屏；低复杂度   |
| B 积水街道      | 第一个环境谜题 | 使用日照降低水位，打开一段道路   | 积水、路障、提示牌       | 0.5屏；低复杂度   |
| C 废弃排水站    | 系统教学节点   | 使用降雨或交互启动排水设施       | 排水站、闸门、控制台     | 0.5屏；中低复杂度 |
| D 被淹广场      | 空间转换区     | 在水位0、1、2之间选择路线        | 广场、公交站、居民2      | 0.5屏；中复杂度   |
| E 居民楼        | 主要救援区     | 将浮箱送到正确停靠点，救援居民1  | 居民楼、窗口、浮箱停靠点 | 0.5屏；中复杂度   |
| F 浮箱转运区    | 核心机制区     | 使用风移动浮箱，完成路线组合     | 浮箱、停靠点、风向提示   | 0.5屏；中高复杂度 |
| G 高地避难所    | 主线结算区     | 带居民抵达安全点，完成关卡       | 避难所、居民、救援标志   | 0.3屏；低复杂度   |
| H 城市边缘      | 剧情过渡区     | 看到洪水向农田和河谷退去         | 城市边界、远景河谷       | 0.3屏；低复杂度   |
| 支路 绿化修复点 | 可选目标区     | 降低水位、清除垃圾、种下小树     | 绿地、垃圾、树苗         | 0.3屏；中低复杂度 |

#### 3 第一关路线逻辑

| 步骤 | 玩家操作                       | 环境变化                                   | 剧情反馈                               |

| 4    | 在D根据路线需要切换雪天或日照  | 雪天形成冰面，日照融冰并让清水水位下降     | 居民2可以通过步行路线接近              |
| 5    | 在F让水保持液态并切换风天      | 浮箱沿停靠点移动一格                       | 风向箭头和浮箱移动音效明确显示路线     |

| 7    | 前往G高地避难所                | 居民抵达安全点，主线完成                   | 城市广播恢复，暴雨声逐渐减弱           |
| 8    | 可选进入支路并切换日照降低水位 | 绿地露出，清除垃圾后种下树苗               | 树苗发光，为农田河谷关卡埋下伏笔       |
