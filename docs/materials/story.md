## 剧情简介

人类破坏了自然的循环，掌管万物复苏的神明伊尔妲因此神体破碎。祂无法降临人间，只能把最后的神力交给一只在洪水中活下来的流浪猫。小猫沿洪水泛滥的城市一路向前走，借风、雨、雪与日照的能力越过受损的农田、河谷到达冰山，种下自然之种，拯救自然和受困的人类。

## 第一关

### 世界观

- 故事发生在：一座被洪水淹没的现代城市。名字、时代和国家都可以模糊处理。
- 灾难发生的真相：这座城市原本建在一条从冰川融水流淌下来的河流两岸。随着城市扩张，人类将河道填埋，改造成狭窄的地下暗渠，并在原有河床上铺设道路、建造楼房。城郊的湿地被填平，农田失去了灌溉的水流，上游的山林被砍光，失去了植被和湿地的蓄水能力，水再也无处可去。暴雨与冰川融水汇入河道后，狭窄且淤塞的地下暗渠无法承受水量，爆发了山洪。
- 城市中心有一座老公园，园里有一棵比城市还古老的大树，树根下就是被水泥封住的泉眼。那是河的源头，也是伊尔妲神体所在的地方。

### 神力设定

神：「伊尔妲」伊尔妲是掌管自然循环、生命延续与万物复苏的神明。祂不能直接替人类完成修复，只能把力量交给猫。

- 性别：中性偏女性
- 外观设定：头发是绿色和银白色渐变。额头中央有一枚嫩芽形状的金色神印
- 标志性道具：圆环悬浮在神的背后
- 神力（赋予小猫的能力）：神力与伊尔妲的道具相连。伊尔妲背后的圆环就是循环本身，分成四段，每一段对应一种天气，也对应自然循环中的一种意义。

| 天气/神力 | 玩法                                   | 循环中的作用 |
| --------- | -------------------------------------- | ------------ |
| 雨        | 升高水位，让浮箱、垃圾桶、木板浮到高处 | 滋润         |
| 风        | 推动漂浮物、吹散烟尘、传播种子         | 流动         |
| 雪        | 把街道水面冻成冰路，冻住急流           | 休眠         |
| 日照      | 融冰、降低水位、让植物长出可攀爬的藤   | 复苏         |

### 人类破坏自然循环伊尔妲的裂痕

- 枯痕：混着油污和垃圾的灰紫色污水，所到之处一片死寂。这是可以被净化的污染。
- 疯长：失控的藤蔓和树根撑裂马路、缠住楼房，那是伊尔妲还在生长的另一半身体。自然在夺回城市，但这种失控的夺回造就了灾难。

### 角色

- 主控角色：小猫
  - 外形：流浪狸花猫。得到神力后额头出现小小的金色嫩芽印记，尾巴尖会微微发光。
  - 猫很少说话，只用短短的句子表达情绪和想法；大多数时候仍然依靠动作回应。
  - 猫施展神力时，身后浮现一个残缺的小圆环，碎片收集得越多（通关越多）就越完整。
- 其他NPC
  - 被困的人类：面目模糊的普通人。可设定为曾经为保护自然做过贡献的人，也可以是依旧正在做着破坏自然的人
  - 被困的动物：被主人丢下的宠物狗、动物园里被淹的动物、在高楼上筑巢的白鹭、流浪猫群（猫的同类）

### 基础剧情

- 序章：那一夜，洪水涌进城市，将所有建筑淹没。所有人都在逃，只有一只流浪猫守在老旧居民楼的屋顶上，因为平时喂它的老人被困在楼里。伊尔妲透过洪水冲开的地面裂痕看见了这只留下来的猫，把残存的神力和额头上的嫩芽神印分给了它。
- 主线：猫沿着被埋掉的河道穿过淹没的城市，从城市边缘一路走向中心的老公园，途中取回散落的圆环碎片（通关奖励），解救被困的人和动物。
- 结局：猫抵达老公园的古树下，伊尔妲的裂痕已经无法靠神力修复。这时，被救过的人们聚到公园，有人开始种树，有人决定把封住河道的水泥掀开，让河重新见到天空。在众人的祈祷和齐心协力下，伊尔妲的裂痕终于得到了修复。
